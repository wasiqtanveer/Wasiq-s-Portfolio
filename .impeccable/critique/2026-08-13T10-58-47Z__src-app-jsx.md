## Design Specificity Verdict

**Category-interchangeable. This is a genre kit, not an identity.**

**LLM assessment.** Swap the name in `Hero.jsx:249` and three project objects in `Projects.jsx:16-44` and this site ships for a different person unchanged. The palette is `#0e0e0e` + `#39FF14` — the single most canonical neon-green hex on the internet — with Unbounded / JetBrains Mono / DM Sans, which is the default dev-portfolio starter triple. The one accent marks ten unrelated things (section numbers, CTA fill, skill pills, hover rims, active filters, availability dot, contribution heat, robot eyes), so it signifies nothing beyond "the site is green."

## Overall Impression

The engineering under this site is better than the design on top of it, and the design is actively hiding the engineering. `App.jsx:256-263` explains why Lenis runs its own rAF instead of `gsap.ticker` (global `lagSmoothing(0)` lets a long frame teleport every in-flight tween). `App.jsx:66-88` uses a layout effect for scroll reset with the failure mode documented. `Scene3D.jsx:226-234` renders at half display rate because canvas repaints force `backdrop-filter` cards to re-blur. That is diagnostic competence — the exact evidence a hiring manager wants — and it is completely invisible to them, while what *is* visible is fourteen borrowed effects.

**The single biggest opportunity:** the work described in `WorkArchive.jsx` is genuinely distinctive and the design ignores it entirely. Everything else on this list is downstream of that one decision.

## What's Working

**Motion engineering that names mechanisms, not symptoms.** `useTilt.js:5-17` explains why one `quickSetter` replaced competing tweens fighting over a single `transform`. `WorkArchive.jsx:250-255` swaps `transition-all` for an explicit property list because the browser was re-transitioning GSAP's own inline writes. These are real diagnoses, preserved in comments.

**Progressive disclosure that doubles as a perf strategy.** `lazyRoutes.js` makes one loader serve both `React.lazy` and the prefetcher, so hovering "View All" warms the chunk and the click resolves with no network wait. `App.jsx:212-217` spends the post-preloader idle gap on below-fold chunks. `GitHubActivity.jsx:77-99` defers the API call until visible, with `GridSkeleton` reserving exact dimensions so there's no CLS. Deferral is applied where attention actually is.

**The contact reassurance layer.** `Contact.jsx:493-530` answers the four questions a prospect actually has — available, when will you reply, what timezone, is a human reading this — and *"I reply to every message personally — no bots, no templates"* converts an act of faith into stated terms. Most portfolios skip this entirely.

## Priority Issues

### [P0] No visible focus indicator anywhere on the site
- **Why it matters:** `index.css:16-19` sets `cursor: none` on every interactive selector for fine pointers, and `outline-none` is applied at `Contact.jsx:120,328,453,467`, `GitHubActivity.jsx:225`, `Footer.jsx:141`. A repo-wide grep for `focus-visible` returns zero matches in shipped code. A keyboard-only visitor has no cursor *and* no focus ring — they cannot tell which field is active. WCAG 2.4.7 failure that blocks the site's only conversion action.
- **Fix:** Delete every `outline-none` above. Add `:focus-visible { outline: 2px solid #39FF14; outline-offset: 3px; }` in `index.css @layer base`. Scope the `cursor: none` rules to `:not(:focus-visible)`. Add a skip-to-content link as the first child of `<main>` (`App.jsx:158`).
- **Suggested command:** `/impeccable harden`

### [P1] Mobile has no navigation and no contact address
- **Why it matters:** `Navigation.jsx:58` and `Footer.jsx:124` are both `hidden md:flex` with no hamburger; `SideNav.jsx` implements a working active-section nav and is never imported. Simultaneously `Contact.jsx:502` hides the info block containing response time, timezone, and `mwasiqt@gmail.com`. On phones the only way to reach a section is scrolling the whole page, and the email address does not exist in the mobile DOM at all — a visitor who won't use the form has no fallback. `Projects.jsx:141` also hides project images on mobile, so phone visitors never see the work.
- **Fix:** Wire up `SideNav.jsx` or add a mobile sheet to `Navigation.jsx:58`. Change `Contact.jsx:502` to `flex` and let rows stack. Surface a `mailto:` in `Footer.jsx:154-161` at all breakpoints. Show project imagery on mobile.
- **Suggested command:** `/impeccable adapt`

### [P1] Form errors are color-and-motion only, with no text and no announcement
- **Why it matters:** `Contact.jsx:288-294` sets boolean flags; name and message failures render only a 300ms shake (`Contact.jsx:283-286`) and a red border (`Contact.jsx:399,455`). Only email gets a message. No label carries `htmlFor`, no input carries `id` or `aria-invalid`, and no `aria-live` region exists, so `loading → success → error` is silent to AT. Three WCAG failures (1.4.1, 3.3.1, 3.3.2) on the conversion path. A screen-reader user submits, hears nothing, and assumes it sent.
- **Fix:** Give each input an `id` paired via `htmlFor`; render per-field messages from an error-string map with `aria-invalid` + `aria-describedby`; wrap the button state in `<div role="status" aria-live="polite">`.
- **Suggested command:** `/impeccable harden`

### [P1] Contradictory contact email and two dead social links
- **Why it matters:** `Contact.jsx:506` lists `mwasiqt@gmail.com`; Waaazek tells users `mwasqit@gmail.com` at `Waaazek.jsx:367,372,383` — `i` and `q` transposed, so one of them bounces silently and an interested recruiter simply never hears back. Separately Twitter/X and Instagram are declared `url: '#'` (`Contact.jsx:70-71`) but rendered `target="_blank"` (`Contact.jsx:184`), so clicking either opens a blank duplicate tab.
- **Fix:** Pick the correct address, hoist it to one exported constant imported by both files. Remove or de-link the two placeholder socials.
- **Suggested command:** `/impeccable clarify`

### [P1] Nothing is allowed to be quiet
- **Why it matters:** Live simultaneously: WebGL ember field, two radial glows, animated grain, redrawing scratch canvas, vignette (`Background.jsx:89-125`), backdrop-blur glass, 3D tilt, neon text-shadow, custom cursor, two infinite marquees, a perpetual scrambling typewriter, a spinning badge, and a robot that pops out every 6s (`Waaazek.jsx:143`). The hero viewport alone runs ten concurrent motion sources with no primary. Cognitive load fails 5 of 8 checks (high). None of these effects is yours; all of them compete with the work.
- **Fix:** Cut to one signature effect and delete the rest. The stack — grain, scratches, vignette, embers, glass, tilt — is entirely generic; removing it costs no identity and returns the page to the projects.
- **Suggested command:** `/impeccable distill`

### [P2] Mandatory ~3.8s gate with a fabricated progress counter
- **Why it matters:** `Preloader.jsx:14` hard-locks 2500ms, plus 1.1s wipe (`Preloader.jsx:71-72`) plus 0.2s fade. The counter reads `fillTween.progress()` (`Preloader.jsx:33-37`) — a fixed 2s tween disconnected from actual loading, so it can display "100" while the gate is still shut. No skip control, no `prefers-reduced-motion` path (contrast `Hero.jsx:42-48`, which handles it correctly). A returning recruiter pays the full toll every visit.
- **Fix:** Drop the minimum to ~800ms; drive the counter from `document.fonts.ready` + image `onload`; add click-to-skip and an immediate bypass under `prefers-reduced-motion`.
- **Suggested command:** `/impeccable optimize`

### [P2] Unsolicited audio on hover, with no mute
- **Why it matters:** Three sources — a click tone on every document `mousedown` (`CustomCursor.jsx:28-56`), a keystroke tick on every character typed into every contact field (`Contact.jsx:394,418,449`), and a tick on every archive row `mouseenter` (`WorkArchive.jsx:169`). A mouse crossing the nine-row list produces machine-gun clicking on the site's best page. No mute exists anywhere.
- **Fix:** Remove `playTick()` from `handleRowEnter`; keep audio on intentional commits only. Add a persistent sound toggle defaulting **off**, in `localStorage`, gating all three call sites.
- **Suggested command:** `/impeccable harden`

## Questions to Consider

1. **What if the site were built the way the tools are built — as an overlay on someone else's interface?** The archive's best work is about injecting missing UI into Amazon's hostile DOM. A landing state that is a screenshot of a bad interface, which the site's chrome visibly rebuilds while you watch, would kill every cliché at once and could not be reused by anyone else — because no one else has that work.

3. **Waaazek is the only authored character here — why is it a corner widget instead of the interface?** A companion that knows this codebase could *be* the navigation, resolving heuristics 6, 7, and 10 in one move.
4. **Would one chosen, unmoving sentence outperform eight rotating ones?** Right now the identity rewrites itself every 4 seconds among options including "Undergrad Student" and "Ships Real Products." What is the cycling buying?
